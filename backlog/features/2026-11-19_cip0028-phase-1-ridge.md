# Task: CIP-0028 Phase 1 (revised) — ridge erf windows

## Description

Replace isotropic Gaussian windows as the shipping weight-space design with **ridge windows in prior-whitened weight space** \(\boldsymbol\omega=\Sigma^{-1/2}\mathbf w\). Each inducing unit is a unit direction \(\mathbf v_m\) plus offset \(a_m\): narrow along \(\mathbf v_m\), equal to \(\sqrt{\mathcal N(\mathbf 0,I)}\) on the orthogonal complement. Land closed-form \(K_{uu}\) (cosine / \(2\times2\) Woodbury) and \(K_{fu}\) (erf in \(\hat{\mathbf x}=\Sigma^{1/2}\tilde{\mathbf x}\)) on `CMlpKern` / `CInducingWeightSpace`, with variance-captured gates. Keep isotropic code only as a \(d\le2\) oracle if useful.

Authoritative write-up: [CIP-0028 Update 2026-11-19](../../cip/cip0028.md#update-2026-11-19-numerical-findings-and-revised-direction). Prototype scripts: [`cip/cip0028/prototype/`](../../cip/cip0028/prototype/).

## Acceptance Criteria

- [x] Ridge \(K_{uu}\) diagonal 1; closed form vs 2-D quadrature; \(O(M^2)\) with no \(D'\) cost in the pairwise kernel
- [x] Ridge \(K_{fu}\) closed form + FD on kernel params through \(\hat{\mathbf x}\) (MC/quad deferred as optional; prototype already checked)
- [x] FD grads for raw centres (directions + offsets) via inducing `gradFromKuuKuf`; kernel-param FD; \(s\) FD helper present
- [x] Variance-captured gate at \(\kappa(K_{uu})\le10^4\): \(\ge0.80\) at \(d=16,M=64\) (measured \(0.88\)); \(M{=}1024\) left to Phase 3 soak
- [x] DTCVAR smoke + stream round-trip with directions + offsets as centres (`M×(d+2)`)
- [x] Isotropic path demoted to oracle (`ridge=false`); default CLI/inducing is ridge

## Implementation Notes

- Centres become directions + offsets (`n_off` per direction; default \(s\) fixed as in CIP-001C).
- ARD is free via input whitening — follow-on Phase 1b revised task can re-gate `CMlpardKern`.
- Do not start Phase 3 polish until this lands.
- Untested in deep / residual stacks; deep remains a future CIP.
