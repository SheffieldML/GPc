# Task: CIP-002D Phase 1 (QW1–QW3)

> Backlog tasks are DOING the work defined in CIPs (HOW).

## Description

Implement Phase 1 of [CIP-002D](../../cip/cip002D.md):

1. **QW1** — Default `make` / CMake to `-O2 -g` with `GPC_CHECKS=1`; keep `RELEASE=1` as checks-off; add `CHECKS=full` / `GPC_CHECKS=2`; point reference CI at full checks. Explicitly revises CIP-0013 bare-`make` policy.
2. **QW2** — Header-inline check helpers with unlikely-branch hints; level 1 = API/dimension invariants; level 2 = per-element bounds and \(O(n^2)\) property scans.
3. **QW3** — Replace the three `lqAdjoint` triple loops with `gemm` (CIP Appendix A).
