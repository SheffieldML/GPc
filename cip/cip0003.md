# CIP-0003: Resolve deferred matio reference mismatches

- [x] Proposed
- [x] Accepted

## Summary

Clear the three backlog bugs deferred from CIP-0001 so the Reference tests hard gate can include ncnm noise, tensor kernels, and `testMatrix` without `continue-on-error`.

## Motivation

CIP-0001 restored a matio-based verification path. Three cases were parked so the gate could go green: Null Category noise numerics, tensor kernel gradients, and matrix/LAPACK fixture disagreements. Leaving them deferred keeps the suite incomplete against Assert Invariants and Verify Against Reference.

## Detailed Description

1. **Tensor kern** — `CTensorKern` slash/copy constructors shallow-copy then re-`addKern`, so gradient “leave-one-out” products include the wrong components. Compute paths never used those ctors, which is why K matched while gradients did not.
2. **ncnm noise** — MATLAB sets `sigma2 = eps`; C++ hard-coded `1e-6`, shifting likelihood and gradients.
3. **testMatrix** — eigenvector sign ambiguity in `syev`; ill-conditioned `trsm` right/upper/non-unit cases disagree with 2005 fixtures (modern LAPACK matches scipy); bound-check crash after `symv` in `sysv`/`ger` path needs a hard fix or guard.

## Implementation Plan

1. Fix tensor slash/copy constructors; free temporary slash kernels; re-enable `testType("tensor")`.
2. Set ncnm `sigma2` to `ndlutil::EPS`; re-enable `testType("ncnm")`.
3. Make `syev` comparisons sign-invariant; refresh ill-conditioned TRSM fixtures from a documented generator; fix or isolate the `sysv` bound failure; require `testMatrix` in CI again.
4. Mark the three backlog tasks Completed and update CIP-0001/REQ-0002 notes.

## Testing Strategy

- Local/CI: `make USE_MATIO=1 matio-tests` then full Reference tests workflow including `testMatrix` without `continue-on-error`.
