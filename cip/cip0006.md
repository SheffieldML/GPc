# CIP-0006: macOS GitHub Actions for compile and soft reference tests

## Status

- [x] Proposed
- [x] Accepted
- [x] In Progress
- [ ] Implemented
- [ ] Closed

## Summary

Extend Compile and Reference tests workflows with a `macos-latest` matrix entry that uses the Homebrew `make.osx` path from CIP-0001. Compile and help smoke are a hard gate on macOS. Matio reference tests run on macOS with `continue-on-error` until the ordered-categorical OpenBLAS mismatch is resolved. Windows remains out of scope.

## Motivation

CIP-0001 closed REQ-0001 with a documented local macOS build. Without CI on that path, Homebrew/GCC/OpenBLAS drift is invisible until someone builds on a Mac. Linux alone does not guard the blessed developer platform. Windows still lacks a maintained make fragment, so a three-OS matrix would invent a toolchain rather than protect one.

## Detailed Description

1. **Compile workflow** — `strategy.matrix` over `ubuntu-latest` + `make.linux` and `macos-latest` + `make.osx`. Install `gcc`, `openblas`, and `libmatio` via Homebrew on macOS; copy `make.osx` to `make.inc`; build `gp`/`ivm`/`gplvm` and run help smoke. Both OSes hard-fail.
2. **Reference tests workflow** — Same OS matrix. Linux remains the hard matio gate. macOS builds and runs `make run-matio-tests` with `continue-on-error: true` while [ordered-categorical noise mismatches](../backlog/bugs/2026-11-13_macos-ordered-categorical-noise-mismatch.md) are open.
3. **`make.osx` resilience** — Select the newest Homebrew `g++-N` / `gfortran-N` instead of hard-coding GCC 16, so Actions and local Cellar majors stay aligned.
4. **Coverage** — Stay on Ubuntu only (gcov/lcov path already wired in CIP-0004).
5. **Out of scope** — Windows CI; making macOS reference tests a hard gate; Accelerate-vs-OpenBLAS dual matrix.

## Implementation Plan

1. Land CIP-0001 `make.osx` (#20) as a prerequisite.
2. Update `make.osx` compiler detection; matrix Compile and Reference tests workflows.
3. Note the soft gate and Windows deferral in the README / CIP status.

## Testing Strategy

- Compile workflow green on Ubuntu and macOS for this PR.
- Reference tests green on Ubuntu; macOS job may report soft failures without blocking merge.
- Local `cp make.osx make.inc && make gp` still works after the compiler-detection change.
