# CIP-0006: macOS GitHub Actions for compile and soft reference tests

- [x] Proposed
- [x] Accepted

- [x] Closed

## Summary

Extend Compile and Reference tests workflows with a `macos-latest` matrix entry that uses the Homebrew `make.osx` path from CIP-0001. Compile, help smoke, and matio reference tests are hard gates on macOS and Ubuntu. The ordered-categorical macOS mismatch was a NaN-to-int cast bug (ARM maps `(int)NaN` to `0`), not OpenBLAS; see the backlog item. Windows remains out of scope.

## Motivation

CIP-0001 closed REQ-0001 with a documented local macOS build. Without CI on that path, Homebrew/GCC/OpenBLAS drift is invisible until someone builds on a Mac. Linux alone does not guard the blessed developer platform. Windows still lacks a maintained make fragment, so a three-OS matrix would invent a toolchain rather than protect one.

## Detailed Description

1. **Compile workflow** — `strategy.matrix` over `ubuntu-latest` + `make.linux` and `macos-latest` + `make.osx`. Install `gcc`, `openblas`, and `libmatio` via Homebrew on macOS; copy `make.osx` to `make.inc`; build `gp`/`ivm`/`gplvm` and run help smoke. Both OSes hard-fail.
2. **Reference tests workflow** — Same OS matrix. Both Ubuntu and macOS are hard matio gates after the ordered-categorical NaN cast fix.
3. **`make.osx` resilience** — Select the newest Homebrew `g++-N` / `gfortran-N` instead of hard-coding GCC 16, so Actions and local Cellar majors stay aligned.
4. **Coverage** — Stay on Ubuntu only (gcov/lcov path already wired in CIP-0004).
5. **Out of scope** — Windows CI; Accelerate-vs-OpenBLAS dual matrix.

## Implementation Plan

1. Land CIP-0001 `make.osx` (#20) as a prerequisite.
2. Update `make.osx` compiler detection; matrix Compile and Reference tests workflows.
3. Note the soft gate and Windows deferral in the README / CIP status.
