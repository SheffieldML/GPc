# CIP-0011: Drive near-complete line coverage of `CGp.cpp`

> CIPs describe HOW to achieve requirements (WHAT). This CIP strengthens [REQ-0002](../requirements/req0002_runnable-verification.md) for the central GP model translation unit, building on the Codecov pipeline from [CIP-0004](cip0004.md).

- [x] Closed - Verified and complete

## Summary

Make `CGp.cpp` a first-class coverage target: measure which lines the matio / diagnostic suite still misses, then add focused drivers (and trim unreachable stubs where appropriate) until **executable** lines in that file are covered under the existing `COVERAGE=1` + Codecov workflow — with an explicit policy for `NotImplementedError` branches and `_NDLMATLAB`-only code.

## Motivation

`CGp` is the hub for FTC / DTC / DTCVAR / FITC / PITC, inducing-point I/O, likelihood / gradients, prediction, and stream round-trips. Project Codecov can look healthy while large arms of `CGp.cpp` remain cold. A file-level gate makes regressions visible.

## Definition of “full coverage”

1. **Line coverage** of every statement that can run in the default Ubuntu Coverage build (`USE_MATIO=1`, no `_NDLMATLAB`).
2. **Throw-site coverage** for intentional stubs we keep (call and assert the throw).
3. **Out of scope for 100%**: `_NDLMATLAB` bodies; jitter-warning branches that need pathological conditioning; rare `equals` mismatch arms once the happy path is covered.

Hard gate: **lcov line rate for `CGp.cpp` ≥ 95%** (raise toward 98% later).

- CI: Coverage workflow runs the 95% gate after lcov filter

## Appendix A — Miss inventory (2026-11-15)

### Baseline (matio suite only, post–000B)

| Metric | Value |
| --- | --- |
| Line rate | **71.2%** (858 / 1205) |
| Functions | 52.9% (27 / 51) |

Cold areas: prediction (`out` / `posteriorMean*`), `optimise` / `optimiseX`, scale learning, free inducing, StableFactor, alternate ctor, expect-throw stubs, stream helpers.

### After `testCGp` + unreachable-tail trim

| Metric | Value |
| --- | --- |
| Line rate | **~96.2%** (1153 / 1199) |
| Functions | 94.1% (48 / 51) |

| Class | Disposition |
| --- | --- |
| Prediction / sparse Alpha / scale learning / `optimiseX` / free inducing / StableFactor / `optimise` / alt ctor | **Cover** via `testCGp` |
| `outGrad*`, `pointLogLikelihood`, non-spherical `updateAD` / Alpha, back-constraints, PITC+`optimiseX`, bad approx / active-set | **Expect-throw** |
| Non-spherical tails in `logLikelihood` / `gpCovGrads` after `updateAD` already throws | **Delete** (CIP-000B policy) |
| Jitter `verbosity>2` warnings; some `equals` false arms; `initDefaultBlockEnd` k==0/>N; back-constraint storage | **Keep** — rare / pathological; listed for a future 98% pass |
| `_NDLMATLAB` | **Out of scope** (not compiled in Coverage) |
