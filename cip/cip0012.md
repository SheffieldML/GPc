# CIP-0012: Whitened StableFactor path with reverse-mode adjoint gradients

## Status

- [x] Proposed - Initial idea documented
- [x] Accepted - Approved, ready to start work
- [x] In Progress - Actively being implemented
- [x] Implemented - Work complete, awaiting verification
- [x] Closed - Verified and complete
- [ ] Rejected - Will not be implemented
- [ ] Deferred - Postponed

## Summary

Complete the `SparseLinalgStableFactor` mode that [CIP-000E](cip000E.md) introduced. Two changes:

1. **Forward pass.** Replace the explicit \(A = K_{uf}K_{uf}^\top + \beta^{-1}K_{uu}\) and its `pdinv` with the *whitened* form \(C = I + \beta BB^\top\), where \(B = U^{-\top}K_{uf}\) and \(U\) is the upper Cholesky factor of \(K_{uu}\) (as stored). Do this for spherical DTC, DTCVAR, FITC and PITC.
2. **Gradients.** Derive them by reverse-mode differentiation of that forward pass, using the adjoints of Cholesky, `trsm` and `syrk` (Murray 2016; Seeger, Hetzel, Dai, Meissner & Lawrence 2017). Neither \(K_{uu}^{-1}\) nor \(A^{-1}\) is ever formed.

**Flag semantics:** this CIP **upgrades `SparseLinalgStableFactor` in place** (same enum / `--sparse-linalg stable`). There is no third mode. After Accept, “StableFactor” means the whitened forward + adjoint gradient path below; CIP-000E’s narrower “trsm for \(V\) only” behaviour is superseded and 000E should be Closed when 0012 lands.

Legacy was the default while whitened LL/grads landed. The **default flip to StableFactor** is the closing soak checkbox (mpmath / `diagSparseStable` green); it shipped in the closing commit of this CIP.

## Motivation: findings from CIP-000E stress experiments (2026-11-15)

`diagDtcvar` uses \(N{=}10, M{=}5\), where cond\((K_{uu})\) is small and the two modes agree to 1e-13. That gate cannot tell the paths apart, so a stress sweep was run:

- **Data:** \(N{=}200\) 1-D points; RBF kernel with inverse width \(\gamma \in \{10^3,10^2,10,1,0.1\}\); \(M \in \{10,20,40,80\}\) evenly spaced inducing points; \(\beta{=}100\).
- **Range:** cond\((K_{uu})\) from 1 to \(1.6\times10^{13}\).
- **Reference:** every state was dumped (the jittered \(K_{uu}\) actually factored, plus \(K_{uf}\) and \(m\)) and re-evaluated in `mpmath` at 60 digits.

### F1. CIP-000E fixes the term it touches

\(\mathrm{diag}(Q_{ff})\) is 5–7 orders of magnitude more accurate under StableFactor:

| | Legacy | StableFactor |
|---|---|---|
| \(\max\lvert q_i - q_i^{\text{ref}}\rvert\), cond ≈ 1e7 | 2e-10 – 3e-9 | 1e-15 – 2e-15 |
| same, cond 1e9 | 3.6e-8 | 2e-14 |
| same, cond 1.6e13 | 1.7e-4 | 1.6e-11 |
| spurious \(q_i > k_{ii}\) (reference has none) | 127/200 (γ=10, M=10); 4/200 (γ=100, M=20) | 0 |

### F2. FITC log-likelihood improves end-to-end

| cond\((K_{uu})\) | Legacy LL error | StableFactor LL error |
|---|---|---|
| ~1e7 | 1e-7 – 4e-4 | 1e-12 – 5e-11 |
| 1e9 | 3.3e-4 | 1.8e-10 |
| 1.6e13 | 2.6e-2 | 1.8e-11 |

These errors are measured after removing the constant offset in F5.

### F3. DTCVAR log-likelihood does not improve

Typical cases have errors of 1e-4 – 2e-2 in **both** modes. At cond 1.6e13 the error is 694 nats (Legacy) and 1,507 nats (StableFactor).

The error comes from the A side:

- \(A\) has roughly the same conditioning as \(K_{uu}\).
- \(A^{-1}\) is formed explicitly with `pdinv`.
- \(\log\lvert A\rvert - \log\lvert K_{uu}\rvert\) subtracts two large, inaccurate numbers.

A plain double-precision prototype of the whitened form (this CIP) on the same states gives:

| cond\((K_{uu})\) | Legacy | StableFactor (000E) | **Whitened** |
|---|---|---|---|
| ~1e7 (15 cases) | 2e-4 – 2e-2 | 9e-5 – 2e-2 | **2e-13 – 6e-11** |
| 1e9 | 2.5e-2 | 2.0e-2 | **2.5e-10** |
| 1.6e13 | 694 | 1,507 | **7.3e-11** |

So the 1.6e13 failure is caused by how A is formed, not by bad input matrices.

### F4. StableFactor gradients are mostly still Legacy

Audit of `CGp::gpCovGrads()`:

| Approx | Uses `_multiplyInvKuu` | Still uses explicit inverses |
|---|---|---|
| DTC | — | `invK_uu` (start of `gK_uu`), `Ainv` throughout |
| DTCVAR | `invK_uuK_uf` only | `invK_uu` (start of `gK_uu`), `Ainv`, `AinvEETAinv`, `AinvK_uf`, `AinvEMT`, β gradient |
| FITC | none | `invK_uuK_uf.symm(invK_uu, …)`, `gK_uu.deepCopy(invK_uu)`, all `Ainv` terms |
| PITC | none (forward pass also uses `Qu.gemm(invK_uu, …)`) | all |

Under StableFactor, the FITC log-likelihood and its gradient are therefore computed from different numerics. They disagree at roughly the size of Legacy's error (up to ~1e-4 here), which can upset line searches. This is the main reason not to switch the default before this CIP lands.

### F5. Related defects (tracked separately)

- **FITC 2π double count** — backlog `2026-11-15_fitc-logtwopi-double-count` (**fixed** 2026-11-16; FITC uses the shared \(2\pi\) tail).
- **`-L` CLI collision** — backlog `2026-11-15_gp-sparse-linalg-cli-collision`.

### F6. End-to-end optimisation (indicative only)

Setup: \(N{=}400\), 200 held-out points, free inducing inputs, 300 iterations, 3 seeds × \(M \in \{15,40,100\}\), identical starting points.

- **FITC:** Legacy: 2 of 9 runs threw `MatrixNonPosDef` during optimisation, and 2 more failed in prediction. StableFactor: 0 training failures and 1 prediction failure.
- **DTCVAR:** no failures in either mode. Final log-likelihoods were equal or better under StableFactor.

Optimisation trajectories diverge between modes, so per-run comparisons are noisy. Treat this as supporting evidence, not as a gate.

## Detailed Description

### Scope

- **In:** spherical Gaussian DTC / DTCVAR / FITC / PITC whitened forward LL; reverse-mode grads into existing `gK_uu` / `gK_uf` / `gLambda` / `gBeta` slots; whitened `posteriorMeanVar` / `out`; high-precision gate; docs.
- **Out:** non-spherical paths (remain `NotImplementedError`); changing Legacy byte-for-byte; Gibbs / multi-output; flipping the default before the soak gate below.

### Code convention (factors)

[CIP-0005](cip0005.md) stores Cholesky factors **upper**. Write \(U=\mathrm{chol}(K_{uu})\) with \(K_{uu}=U^\top U\). All `trsm` calls use `uplo='U'` with explicit `trans` flags. In prose, \(B = U^{-\top}K_{uf}\) (one triangular solve). When citing Murray / Seeger who use lower \(L\), map \(L \leftrightarrow U^\top\) once in the adjoint helpers — do not mix \(L_u\) and \(U\) in the same formula block.

### Notation

- \(U = \mathrm{chol}(K_{uu})\), upper (cached as `LcholK`).
- \(B = U^{-\top}K_{uf}\), size \(M \times N\).
- \(\Lambda\) is the per-approximation noise: \(\beta^{-1}I\) for DTC/DTCVAR, the FITC diagonal \(\beta^{-1}\mathrm{diag}(1 + \beta(k_{ii} - q_i))\), or the PITC block diagonal.
- \(C = I + B\Lambda^{-1}B^\top\), with \(U_c = \mathrm{chol}(C)\) stored upper. Eigenvalues of \(C\) are at least 1.

### Forward pass (per output column \(m\))

1. `jitChol` \(K_{uu} \to U\). Reuse `LcholK` with the existing jitter policy.
2. \(B \leftarrow U^{-\top}K_{uf}\): one `trsm`, replacing `_multiplyInvKuu`'s two.
3. \(q_i = \lVert B_{:,i}\rVert^2\): column sums of squares. This replaces `V = invK_uu K_uf ∘ K_uf`.
4. Form \(\Lambda\) (DTCVAR trace term, FITC diagonal, PITC blocks).
5. \(C \leftarrow I + B\Lambda^{-1}B^\top\) via `syrk` on \(B\Lambda^{-1/2}\). Then `jitChol` \(C \to U_c\).
6. \(c \leftarrow U_c^{-\top}B\Lambda^{-1}m\) (then \(U_c^{-1}\) as needed).
7. \(-2\,\mathcal{L} = \log\lvert C\rvert + \log\lvert\Lambda\rvert + m^\top\Lambda^{-1}m - \lVert c\rVert^2 + \text{(DTCVAR: } \beta\textstyle\sum_i(k_{ii} - q_i)) + dN\log 2\pi\).

There is no `pdinv` and no \(\log\lvert K_{uu}\rvert\). FITC reduces to the same structure with a diagonal \(\Lambda\), and PITC with a block-diagonal one (block Cholesky solves replace `blockDinv`).

### Gradients (reverse mode)

Shared machinery (unit-tested):

1. **`trsm` adjoint** for \(B = U^{-\top}K_{uf}\): \(\bar K_{uf} = U^{-1}\bar B\) and the corresponding \(\bar U\) contribution (Murray / Seeger; implement against upper storage).
2. **Cholesky adjoint** mapping \(\bar U \to \bar K_{uu}\) (symmetric): **Murray Level-3 blocked reverse** (Accept decisions below). Unblocked / symbolic forms are oracles only.

Every solve is a `trsm` against an existing factor.

#### DTC / DTCVAR (spherical; formulae validated)

For spherical DTCVAR with one output column (sum over columns for \(d > 1\)), let \(u = Bm\) and \(a = C^{-1}u\). Then:

\[
\bar B = 2\beta C^{-1}B - 2\beta^2 a m^\top + 2\beta^3 a a^\top B - 2\beta B,
\]
\[
\partial_\beta(-2\mathcal{L}) = \mathrm{tr}(C^{-1}BB^\top) - \tfrac{N}{\beta} + m^\top m - 2\beta\,u^\top a + \beta^2\lVert B^\top a\rVert^2 + \textstyle\sum_i k_{ii} - \lVert B\rVert_F^2,
\]
\[
\partial_{k_{ii}}(-2\mathcal{L}) = \beta \quad\text{(maps onto existing \texttt{gLambda} / diagonal-kernel gradient)}.
\]

These, chained through the shared adjoints, were checked against central differences in a NumPy prototype (\(M{=}6, N{=}30\), cond ≈ 3e3). Relative error converges as \(h^2\), down to 3e-8 for \(\bar K_{uf}\) and 2e-7 for \(\bar K_{uu}\) and \(\beta\).

DTC is the same structure without the DTCVAR diagonal / \(\sum(k_{ii}-q_i)\) terms.

#### FITC / PITC (derive in-PR; gate-validated)

FITC and PITC reuse the same `_trsmAdjoint` / `_cholAdjoint` and the whitened \(C\) path. Extra work:

- **FITC:** \(\Lambda=\Lambda(q(B))\) with \(q_i=\lVert B_{:,i}\rVert^2\). Reverse mode must accumulate \(\bar q \to \bar B\) (column scaling) in addition to the DTC-like \(\bar B\) through \(C\). Write the \(\bar\Lambda\) / \(\bar q\) expressions in the implementing PR (or an appendix update to this CIP) before merging grads; validate with the mpmath gate, not FD alone.
- **PITC:** \(\Lambda\) is block-diagonal; reverse mode uses per-block Cholesky adjoints of the \(D\) blocks plus the shared \(C\) path. Same documentation and gate rule as FITC.

Accept of this CIP authorises that derivation-in-PR pattern for FITC/PITC; it does **not** authorise merging FITC/PITC grads without either explicit formulae in the PR description or a filled CIP appendix.

The resulting \(\bar K_{uu}\), \(\bar K_{uf}\) and \(\bar k_{ff}\) feed the existing `gK_uu` / `gK_uf` / `gLambda` slots. Kernel and inducing-input chain rules are unchanged.

### Code structure

- New private helpers in `CGp`: `_whitenKuf` (step 2), `_trsmAdjoint`, `_cholAdjoint`, and a per-approximation `_whitenedForward` / `_whitenedBackward`.
- `updateAD()` and `gpCovGrads()` branch once on `isStableSparseLinalg()`. The Legacy code stays byte-for-byte unchanged so dual-path comparisons stay meaningful.
- New cached state (`B`, `LcholC` / \(U_c\), `c`, per-block factors for PITC) joins the [CIP-0009](cip0009.md) cache protocol: invalidated by the same mutators, refreshed by `ensureADUpToDate`.
- Prediction (`posteriorMeanVar`, `out`) gets the whitened path as a step in this CIP (same \(U, U_c\)).
- `_multiplyInvKuu` stays for Legacy only and is retired once the default flips (final checkbox).

### Alternatives considered

- **Third enum `SparseLinalgWhitened`** — Rejected for user-facing API; upgrade StableFactor in place and keep Legacy for archaeology.
- **Flip default in the first merge** — Rejected; F4 and optimisation noise require soak under the flag first.
- **FD-only gates** — Rejected; see Testing Strategy.
- **Separate “Murray blocked CIP”** — Rejected 2026-11-16. Cholesky reverse ownership stays here; do not fork a parallel performance CIP for the adjoint alone. Kernel/BLAS wall-clock work stays in [CIP-0013](cip0013.md).

## Accept decisions (2026-11-16)

Accepted after reviewing GPy [CIP-000E](https://github.com/SheffieldML/GPy/blob/cip000E-numpy-blas-primitives/cip/cip000E.md) (`cip000E-numpy-blas-primitives`): Murray blocked Cholesky VJP as the wired default, with the process lesson that a correctness-matched column-matvec / unblocked substitute **lost** measured races to Cython on Apple Accelerate, while Level-3 blocked cleared the bar.

1. **`_cholAdjoint` algorithm.** Implement Murray (2016) **blocked** reverse (`chol_blocked_rev` / GPy `cholesky_vjp_blocked` spirit): Level-3 triangular solves and matrix–matrix products on diagonal blocks (default block width tunable, e.g. 64–128). Map Murray/Seeger **lower** \(L\) formulae onto GPc **upper** \(U\) storage once (`L \leftrightarrow U^\top`); do not mix conventions in one helper.
2. **Oracles only.** Unblocked Smith-style loops and Murray symbolic reverse on the full factor are allowed as unit-test oracles and for tiny diagonal blocks inside the blocked algorithm. They must **not** be the production `_cholAdjoint` path for large factors.
3. **No weaker “BLAS-shaped” substitute.** A column-matvec or Level-2-only VJP that matches FD/mpmath but loses a dual-path timing gate against blocked Murray does **not** ship as the StableFactor default adjoint. Record A/B timings (blocked vs oracle) before any default flip of StableFactor.
4. **Reusable primitive.** `_cholAdjoint` / `_trsmAdjoint` stay pure numerical helpers (factors + cotangents in, cotangents out) so Bayesian GPLVM / MRD paths can reuse them without embedding model observers.
5. **Scope boundary.** GPy CIP-000E’s stationary-grad / Cython-removal lessons map to [CIP-0013](cip0013.md) (bulk kernel, within-evaluation \(r^2\)/`K` reuse), not to this CIP. This Accept does not enlarge 0012 into kernel GEMM work.
6. **Legacy default unchanged** until the existing soak / mpmath checkbox. Accept authorises implementation under `--sparse-linalg stable` / `SparseLinalgStableFactor`.

## Testing Strategy

Finite differences cannot resolve 1e-4-level errors when cond\((K_{uu})\) is around 1e7. The hard gate is against an extended-precision reference.

1. **`diagSparseStable`** (new driver): γ × M sweep for each approximation; dumps \(K_{uu}\) (post-jitter), \(K_{uf}\), \(m\), β, and each mode's LL, \(q\), gradients.
2. **`scripts/sparse_mp_reference.py`**: recomputes LL, \(q\), grads at 60 digits with `mpmath`.
3. **CI vs maintainer:** `diagSparseStable` is a **hard local/CI gate** once wired (like `diagDtcvar`). The mpmath script may run in CI if `mpmath` is pinned in the Coverage or a dedicated job; until then it is a **required maintainer gate** before merge (document the pin in `docs/numerics.md`). Do not merge whitened grads without a recorded mpmath pass attached to the PR.
4. **Gates:**
   - cond\((K_{uu}) \le 10^{9}\): StableFactor LL relative error ≤ 1e-10, gradient relative error ≤ 1e-8, zero spurious \(q_i > k_{ii}\).
   - cond up to 1e13: StableFactor LL error ≤ 1e-8.
   - StableFactor no worse than Legacy in every cell.
5. **Existing gates stay green:** `diagDtcvar`, `diagPitc`, matio suite with default **Legacy**, CIP-0011 `CGp.cpp` coverage (extend `testCGp` for new branches).
6. **Optimisation smoke (non-gating):** F6 protocol; report failures and held-out NLPD.
7. **Performance re-benchmark (non-gating for CIP-0013):** after the whitened path lands, re-run the [CIP-0013](cip0013.md) harness. A sparse ratio of at most 1.1× GPy on that q=2, one-thread protocol is a check on this CIP. [REQ-0007](../requirements/req0007_competitive-default-build.md) closes at 1.3×, and CIP-0013 does not wait for this check.

## Appendix A — FITC reverse (spherical, StableFactor)

With \(B=U^{-\top}K_{uf}\), \(D_i=1+\beta(k_{ii}-q_i)\), \(q_i=\lVert B_{:,i}\rVert^2\), \(V=B D^{-1/2}\), \(C=I+\beta VV^\top\), \(w=m./D\), \(u=Bw\), \(a=C^{-1}u\):

\[
-2\mathcal{L}=\textstyle\sum_i\log D_i+\log\lvert C\rvert-N\log\beta+\beta m^\top w-\beta^2 u^\top a
\]
(plus output dim and \(2\pi\)/prior tails as in `logLikelihood`).

Reverse (per output column, then sum): \(\bar C=C^{-1}+\beta^2 aa^\top\), \(\bar V=2\beta\bar C V\), \(\bar u=-2\beta^2 a\), \(\bar B\leftarrow\bar u w^\top+\bar V./\sqrt{D}\), \(\bar D\) from \(\log D\), \(w\), and \(V\) scale, then \(\bar B\leftarrow\bar B-2\beta\bar D_i B_{:,i}\). Chain \(\bar B\) through `trsmAdjointUT` / blocked chol; half off-diag of \(\bar K_{uu}\) for kernel Frobenius storage. \(\partial\mathcal{L}/\partial k_{ii}=-\tfrac12\bar D_i\beta\).

## Appendix B — PITC reverse (spherical, StableFactor)

With \(B=U^{-\top}K_{uf}\), contiguous blocks \(b\), \(Q_b=B_b^\top B_b\), \(D_b=I+\beta(K_b-Q_b)\), \(C=I+\beta\sum_b B_b D_b^{-1}B_b^\top\), \(u=\sum_b B_b D_b^{-1}m_b\), \(a=C^{-1}u\):

\[
-2\mathcal{L}=\log\lvert C\rvert+\textstyle\sum_b\log\lvert D_b\rvert-N\log\beta+\beta\sum_b m_b^\top D_b^{-1}m_b-\beta^2 u^\top a
\]
(plus output-dim scaling and \(2\pi\)/prior tails as in `logLikelihood`).

Reverse (per output column, then sum; \(\bar C=C^{-1}+\beta^2 aa^\top\), \(\bar u=-2\beta^2 a\)): for each block, \(\bar B_b\leftarrow 2\beta\bar C B_b D_b^{-1}+\bar u(D_b^{-1}m_b)^\top\), and with \(v=B_b^\top\bar u\),

\[
\overline{D^{-1}}=\beta\,\mathrm{sym}(B_b^\top\bar C B_b)+\tfrac12(vm_b^\top+m_b v^\top)+\beta m_b m_b^\top,\qquad
\bar D=D^{-1}-D^{-1}\overline{D^{-1}}D^{-1}
\]
(then \(\bar B_b\leftarrow\bar B_b-2\beta B_b\bar D\)). Symmetrise the \(vm^\top\) term — the unsymmetric outer alone fails FD. Chain \(\bar B\) through `trsmAdjointUT` / blocked chol; half off-diag of \(\bar K_{uu}\) for kernel Frobenius storage. \(\partial\mathcal{L}/\partial K_b=-\tfrac12\beta\bar D\); \(\partial\mathcal{L}/\partial\beta=-\sum_b\mathrm{tr}(g_{\Lambda_b})/\beta^2\) with \(g_{\Lambda_b}=\partial\mathcal{L}/\partial K_b\).
