# CIP-0029: Green's-function (causal-root) inducing features for 1-D kernels

## Summary

Add a fourth inducing-variable family, **Green's-function (causal-root) features**, for **1-D** processes that admit a causal spectral factor \(g\) with \(g*g=k\) (support on \([0,\infty)\)). Inducing variables are again defined on white noise through fixed windows \(\psi_m\),

\[
u_m = \int \psi_m(t)\, w(t)\,\mathrm{d}t,
\qquad
K_{uu}[m,n]=\langle\psi_m,\psi_n\rangle,
\qquad
K_{fu}(x,m)=(g*\psi_m)(x),
\]

so \(K_{uu}\) is kernel-free. Choosing the **causal** factor \(g\) (instead of the symmetric \(\sqrt{S}\) convolution of CIP-001C) yields closed-form **erf** and **smoothed-ReLU** units for Brownian / integrated Brownian, and exponentially tempered analogues for causal Matérn.

This is still variational DTC / DTCVAR: a finite inducing approximation to a non-parametric GP prior — the same epistemology as point inducing and CIP-001C white-noise features.

## Motivation

### Why not only CIP-001C Hankel?

CIP-001C Phase 3 builds \(K_{fu}\) from the **symmetric** spectral factor \(\sqrt{S(\rho)}\) via a Hankel transform. That is the right default for isotropic stationary kernels on \(\mathbb{R}^d\).

For **1-D time-like** inputs, many kernels also have a **causal** Green's function (Markov / SDE representation): \(g(t)=0\) for \(t<0\). Convolving causal \(g\) with a Gaussian window \(\psi_m\) produces elementary special functions (erf, smoothed ramps) that are cheap, interpretable as temporal basis units, and natural for Brownian and Matérn-\(\nu=p+1/2\) SDEs. CIP-001C listed this explicitly as a non-goal / future CIP.

### What problem it solves

- Sparse Brownian / integrated-Brownian / causal Matérn fits where point inducing \(K_{uu}=k(Z,Z)\) is awkward (non-stationary Brownian; lengthscale-driven ill-conditioning for Matérn).
- A clean 1-D path to **erf** and **smoothed-ReLU** inducing features *without* leaving the GP+DTCVAR story (contrast: a finite parametric spline or NN).
- Complements CIP-0028: there erf/ReLU arise from **weight-space** windows on MLP/arccos; here they arise from **causal convolution** on the input line.

## Detailed Description

### Relationship to CIP-001C

| | CIP-001C white-noise | CIP-0029 Green's / causal |
|---|---|---|
| White-noise drive | yes | yes |
| \(K_{uu}\) | \(\langle\psi,\psi\rangle\) (kernel-free) | same |
| Factor of \(k\) | symmetric \(\sqrt{S}\) (Hankel / RBF closed form) | causal \(g\) with \(g*g=k\), \(g(t)=0\) for \(t<0\) |
| Domain | \(\mathbb{R}^d\) (isotropic / RBF-ARD) | **1-D** input (time or ordered index) |
| `CInducing` type | `whitenoise` | new `greens` / `causal` (name TBD; prefer `greens`) |

Both reuse StableFactor / LQ unchanged. Implementation should share Gaussian-window \(K_{uu}\) helpers with `CInducingWhiteNoise` where the window algebra coincides (1-D special case).

### Target kernels and closed forms (Phase 1–2)

Windows: L²-normalised Gaussians \(\psi_m(t)=(4\pi s^2)^{1/4}\mathcal N(t;z_m,s^2)\) (same normalisation convention as CIP-001C in 1-D).

1. **Brownian** (\(k(x,x')=\sigma^2\min(x,x')\) on a same-signed 1-D index; existing `CBrownianKern`):
   - Causal root is a step / indicator (Wiener): convolution with \(\psi_m\) yields a scaled **\(\Phi((x-z_m)/s)\)** (erf) unit for \(K_{fu}\).
   - Pin constants against direct numerical convolution and against the known Brownian covariance.

2. **Integrated Brownian** (optional new kernel or Brownian-on-integrated state):
   - Causal root is a ramp; \(g*\psi_m\) is a **Gaussian-smoothed ReLU** (ramp×Gaussian cumulative structure).
   - Either add `CIntegratedBrownianKern` or document as a derived feature path on an extended state — prefer a small explicit kernel if GPy parity is thin; otherwise keep as inducing-only helper gated by tests.

3. **Causal Matérn** \(\nu=1/2,3/2,5/2\) (Exp / Matérn already in tree as stationary isotropic):
   - SDE Green's function \(g(t)\propto t^{p}e^{-\lambda t}\mathbf{1}_{t\ge0}\) (order \(p\) tied to \(\nu\)).
   - \(g*\psi_m\) = exponentially tempered erf / smoothed polynomials (closed form via repeated integration by parts / Mill's ratio style terms).
   - Gate: for large \(s\) relative to \(\lambda^{-1}\), numerical convolution matches; for RBF there is **no** finite-order causal Matérn root — RBF stays on CIP-001C symmetric path only.

### Non-parametric status (explicit)

Prior remains \(f\sim\mathcal{GP}(0,k)\). Inducing variables are linear functionals of the white-noise drive of the causal factorisation. Sparse inference is DTC / DTCVAR / FITC / PITC through `CInducing` — the same finite variational approximation as vardtc, not a parametric erf/ReLU network that replaces the GP.

### Phase plan

#### Phase 0 — `CInducingGreens` skeleton

- New `CInducing` implementation: `typeName()=="greens"`, `kuuDependsOnKernel()==false`, centres \(z_m\in\mathbb{R}\) (`domainDim()==1`), window width \(s\).
- Assert `getInputDim()==1` (or single active dimension) when this family is selected; clear error otherwise.
- CLI: `--inducing greens` (or `causal`); reuse `--window-width`.
- Stream: `inducingType=greens`, `windowWidth=`; centres via existing `X_u` rows (1-D) — **unlike CIP-0028**, centres stay in input space, so `X_u` ownership matches white-noise inducing.

#### Phase 1 — Brownian erf path

- `CBrownianKern` cross-feature API (kernel virtuals or greens-specific hooks parallel to `wnCross*`).
- Closed-form \(K_{fu}\), grads w.r.t. \(\sigma^2\), \(z_m\), \(s\), \(x\).
- Gates: MC/numeric convolution; FD; DTCVAR smoke; \(\kappa(K_{uu})\) independent of Brownian variance on a sweep.

#### Phase 2 — Causal Matérn / Exp

- Map Exp → Matérn-\(\nu=1/2\) causal root; Matérn 3/2 and 5/2 similarly.
- Prefer implementing on existing `CExpKern` / `CMatern32Kern` / `CMatern52Kern` with a `greensCross*` path (throw on \(d\neq1\)).
- Numeric convolution gates; optional comparison to CIP-001C Hankel \(K_{fu}\) (different features, same \(k\) — likelihoods need not match for fixed \(Z,s\)).

#### Phase 3 — Integrated Brownian / smoothed ReLU (stretch)

- Ship only if Phase 1–2 are green and the kernel surface is agreed (new type vs state augmentation).
- Document as the 1-D “smoothed ReLU unit” counterpart to CIP-0028 arc-cosine order 1.

#### Phase 4 — Polish

- Stability cells `greens_var_sweep_*` / lengthscale sweep for Matérn.
- README / `docs/numerics.md`: when to use `points` vs `whitenoise` vs `greens` vs `weightspace`.
- Compression after Close.

### Explicit non-goals

- Multi-dimensional causal / SPDE Green's functions (Matérn on \(\mathbb{R}^d\) via Whittle) — separate research CIP.
- Weight-space MLP / arc-cosine (CIP-0028).
- Replacing CIP-001C Hankel for RBF in \(d>1\).
- Learning \(s\) by default; psi / BGPLVM with greens features.
- Changing `CBrownianKern` point-inducing behaviour or GPy Brownian semantics.
- **ODE / LFM / SIM covariance families** as `CKern` types — still out of scope here (same non-goal as [REQ-0005](../requirements/req0005_gpy-aligned-kernel-coverage.md) / [REQ-0006](../requirements/req0006_multioutput-covariance.md) / [CIP-000D](./cip000D.md)). See **Future CIPs** below for how this CIP prepares that work.

### Alternatives considered

1. **Only use symmetric Hankel for Brownian.** Rejected for 1-D: Brownian is non-stationary; Bochner/\(\sqrt{S}\) does not apply. Causal factor is the native representation.
2. **Finite erf/ReLU dictionary without a GP prior.** Rejected: breaks REQ-000D / vardtc epistemology the project wants.
3. **Fold into `CInducingWhiteNoise` with a `factor=symmetric|causal` flag.** Attractive for code share; rejected as the *public* type string — keep a distinct `greens` family so CLI/stream stay explicit; share private window-Gram helpers.

## Future CIPs (pointers, not scope)

- **Latent force / SIM / ODE covariance (`CKern`):** a follow-on CIP (unnumbered) should add LFM-style kernels where each output is \(x_d = G_d * f\) for a latent force \(f\sim\mathcal{GP}(0,k_f)\) and ODE Green's function \(G_d\), so \(k_{x_d,x_{d'}} = G_d * k_f * G_{d'}^\top\). That is a **new covariance family**, not an inducing type. This CIP does **not** ship it, but is deliberate groundwork:
  - **Shared analytics:** closed-form convolutions of causal \(G\) (exp-decay / Matérn roots) with Gaussian windows — the same special-function stack used here for \(g*\psi_m\) — should be factored so an LFM `computeElement` can reuse them for the double convolution with \(k_f\) (typically RBF).
  - **Sparse path:** induce on the **latent force** (point, [CIP-001C](./cip001C.md) white-noise, or this greens family when the force factorisation fits), then push cross-covariances through \(G_d\); that matches the Álvarez et al. multioutput VIK setting and keeps \(K_{uu}\) on the force side kernel-free when desired.
  - **Multi-output wiring:** stack on [CIP-000D](./cip000D.md) ICM/LCM only where appropriate; LFM cross-output structure is usually through shared forces, not a free \(B\) coregionalization matrix — the follow-on CIP must spell that composition out.
  - **Non-goal reminder:** [CIP-0028](./cip0028.md) weight-space MLP/arccos remains orthogonal to LFM.
