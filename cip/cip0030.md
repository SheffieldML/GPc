# CIP-0030: Uncollapsed Bayesian GP-LVM — sampled \(q(\mathbf X)\) on the SVGP machinery, for any inducing family

> CIPs describe HOW to achieve requirements (WHAT). This CIP implements [REQ-0018](../requirements/req0018_bayesian-gplvm-without-psi-statistics.md): a Bayesian GP-LVM that needs no closed-form psi statistics. It reuses the SVGP core from [CIP-002A](./cip002A.md) and runs through `CInducing`, so weight-space MLP features ([CIP-0028](./cip0028.md)), white-noise windows ([CIP-001C](./cip001C.md)) and Green's features ([CIP-0029](./cip0029.md)) all become usable for latent-variable models.

## Summary

Replace the analytic expectations over \(q(\mathbf X)\) (psi statistics) with reparameterised samples \(\tilde{\mathbf x}_n=\boldsymbol\mu_n+\mathbf s_n\odot\boldsymbol\epsilon_n\) inside the **uncollapsed** SVGP bound. The resulting estimator of the ELBO is unbiased; it is the uncollapsed counterpart of Titsias & Lawrence (2010) and an instance of doubly stochastic variational inference (Titsias & Lázaro-Gredilla 2014). It needs only three things, all already in GPc:

- the cross-covariance \(K_{u}(\tilde{\mathbf x})\) and its input gradient: `CInducing::computeKuf` and `gradFromKuuKuf(..., wantX)`, implemented by all four inducing families;
- the kernel diagonal and its input gradient: `diagComputeElement`, `getDiagGradX`;
- the explicit whitened \(q(\mathbf u)\), natural-gradient steps, Adam and minibatches of `CSvgp` / `CAdam`.

**Prerequisite gaps** (Phase 0):
- `CSvgp` still builds \(K_{uu}\), \(K_{uf}\) from plain points \(\mathbf Z\) rather than through `CInducing`;
- `CSvgp` does not return gradients with respect to its inputs.

## Motivation

- `CBayesGplvm` / `CMrd` call `CKern::psi0/1/2(mu, S, Z)` with point inducing. Psi statistics exist for White, Bias, Linear, RBF, RBF-ARD and compounds of these. `CInducing` has no psi interface.
- For the MLP kernel with weight-space ridge features, \(K_{fu}(\mathbf x,m)\propto\operatorname{erf}\big(\mu_m\mathbf v_m^\top\hat{\mathbf x}\,/\sqrt{1+2(\|\hat{\mathbf x}\|^2-(1-c_s)(\mathbf v_m^\top\hat{\mathbf x})^2)}\big)\). Its Gaussian expectation has no closed form, because the denominator couples the projection with the norm, and neither does \(\psi_0\) (the MLP diagonal is an arcsine of a function of \(\|\hat{\mathbf x}\|^2\)).
- Numerical psi statistics (Gauss–Hermite over the latent space) scale exponentially with latent dimension. Approximating \(\|\hat{\mathbf x}\|^2\) by its mean gives closed forms but no longer a bound.
- The uncollapsed sampled bound avoids all of this, keeps a lower bound in expectation, and adds minibatching over data points for free.

## Detailed Description

### Model and bound

\(p(\mathbf X)=\prod_n\mathcal N(\mathbf x_n\mid\mathbf 0,I)\); \(q(\mathbf X)=\prod_n\mathcal N(\boldsymbol\mu_n,\operatorname{diag}\mathbf S_n)\). For each output column \(j\), an inter-domain inducing vector \(\mathbf u_j\) with whitened \(q(\mathbf v_j)=\mathcal N(\tilde{\mathbf m}_j,\tilde S_j)\), \(\mathbf u_j=L\mathbf v_j\), \(K_{uu}=LL^\top\) (from `CInducing::computeKuu`).

\[
\mathcal L=\sum_{n,j}\mathbb E_{q(\mathbf x_n)}\mathbb E_{q(f_{nj}\mid\mathbf x_n)}\big[\log p(y_{nj}\mid f_{nj})\big]
-\sum_j\mathrm{KL}\big(q(\mathbf v_j)\,\|\,\mathcal N(\mathbf 0,I)\big)
-\sum_n\mathrm{KL}\big(q(\mathbf x_n)\,\|\,\mathcal N(\mathbf 0,I)\big),
\]

where, with \(\mathbf a(\mathbf x)=L^{-1}K_u(\mathbf x)\),

\[
q(f_{nj}\mid\mathbf x)=\mathcal N\big(\mathbf a^\top\tilde{\mathbf m}_j,\;k(\mathbf x,\mathbf x)+\mathbf a^\top(\tilde S_j-I)\mathbf a\big).
\]

**Estimator.** For a minibatch \(B\) and \(K\) samples per point, \(\tilde{\mathbf x}_{nk}=\boldsymbol\mu_n+\mathbf s_n\odot\boldsymbol\epsilon_{nk}\), \(\mathbf s_n=\sqrt{\mathbf S_n}\):

\[
\hat{\mathcal L}=\frac{N}{|B|K}\sum_{n\in B,k,j}\mathbb E_{\mathcal N(f\mid\mu_{nkj},v_{nkj})}\log p(y_{nj}\mid f)
-\sum_j\mathrm{KL}_j-\frac{N}{|B|}\sum_{n\in B}\mathrm{KL}\big(q(\mathbf x_n)\|p\big).
\]

The inner expectation is closed form for Gaussian noise and Gauss–Hermite for probit / ordered (existing `CSvgp` path). \(\mathbb E_{\epsilon,B}[\hat{\mathcal L}]=\mathcal L\), for the Gauss–Hermite-approximated objective in the non-Gaussian case.

### Gradients

Let \(g^\mu,g^v\) be the derivatives of the inner expectation with respect to the marginal mean and variance (as in `CSvgp`). Then:

- **Per sample:** \(\partial/\partial\mathbf a=g^\mu\tilde{\mathbf m}_j+2g^v(\tilde S_j-I)\mathbf a\); the column of \(\bar K_{uB}=L^{-\top}\,\partial/\partial\mathbf a\) (summed over \(j\)); and \(\partial/\partial k(\tilde{\mathbf x},\tilde{\mathbf x})=g^v\).
- **Inputs:** \(\partial\hat{\mathcal L}/\partial\tilde{\mathbf x}\) = `gradFromKuuKuf(..., gKuf = \bar K_{uB}, wantX = true)` + \(g^v\cdot\)`getDiagGradX`. \(K_{uu}\) does not depend on \(\mathbf x\).
- **Local parameters:** \(\partial/\partial\boldsymbol\mu_n=\sum_k\partial/\partial\tilde{\mathbf x}_{nk}\); \(\partial/\partial\mathbf s_n=\sum_k\partial/\partial\tilde{\mathbf x}_{nk}\odot\boldsymbol\epsilon_{nk}\). Parameterise \(\log\mathbf S\): \(\partial/\partial\log\mathbf S=\tfrac12\mathbf s\odot\partial/\partial\mathbf s\). Add the KL terms \(-\boldsymbol\mu_n\) and \(-\tfrac12(\mathbf S_n-1)\) (with respect to \(\log\mathbf S\)), scaled by \(N/|B|\).
- **Global parameters** (kernel, inducing parameters, noise): exactly `CSvgp`'s Phase 2 path, evaluated at \(\tilde{\mathbf X}_B\) rather than fixed \(\mathbf X\). That path whitens through `trsmAdjointUT` / `cholAdjointUpperBlocked`, routed via `CInducing::gradFromKuuKuf`.

### Optimisation

- **\(q(\mathbf v)\):** CVI natural-gradient step (CIP-002A) with sites built from \(\mathbf a(\tilde{\mathbf x}_{nk})\) and weight \(c=N/(|B|K)\). The step is linear in the sites, so it is unbiased in natural-parameter space, and it stays positive definite for log-concave likelihoods (\(g^v\le0\)). Because \(\mathbf x\) is sampled, use \(\gamma<1\) with a decaying schedule even at full batch.
- **Global parameters:** Adam (`CAdam`).
- **Local parameters** \((\boldsymbol\mu_n,\log\mathbf S_n)\): a separate parameter group updated only for \(n\in B\) (row-sparse Adam). A dense Adam would decay the moments of rows outside the batch on zero gradients. Optionally, take several local steps per global step.
- **Variance control:** \(K\) samples per point (default 1), optional antithetic pairs \((\boldsymbol\epsilon,-\boldsymbol\epsilon)\), common random numbers for diagnostics.
- **Initialisation:** \(\boldsymbol\mu\) by PCA (`initXpca`), \(\mathbf S=0.5\). Inducing parameters per family: points from \(\boldsymbol\mu\) (`initZFromMu`); ridge directions by the CIP-0028 orthogonal / \(\kappa\)-budget initialisation. Optionally warm-start from a collapsed RBF `CBayesGplvm` fit.

### Code structure

1. **`CSvgp` through `CInducing` (Phase 0a).** Own a `CInducing*` (as `CGp` does). The existing `Z` constructor wraps an owned `CInducingPoints` pointing at member centres storage, so behaviour and fixtures are unchanged. A `setInducing(CInducing*)` takes ownership for white-noise / weight-space / Green's. \(K_{uu}\), \(K_{uB}\) and their gradients go through the inducing object. This also gives plain SVGP all four inducing families.
2. **Explicit-input core (Phase 0b).** Factor `CSvgp`'s data term, sites and gradients into protected methods that take an input block \(\tilde{\mathbf X}_B\), row indices into \(\mathbf Y\), a weight \(c\), and an optional `CMatrix* gX`. The public `CSvgp` API calls them with rows of its fixed \(\mathbf X\). Keep this core free of \(\mathrm{KL}(q(\mathbf X)\|p(\mathbf X))\) and of \((\boldsymbol\mu,\log\mathbf S)\) ownership — those stay in `CSviBayesGplvm` so a later deep-GP CIP can stack the same core (Salimbeni & Deisenroth 2017) without reopening SVGP. Batched BLAS-3 form as in [CIP-002D](./cip002D.md) QW6.
3. **`CSviBayesGplvm : CStochasticOptimisable` (Phase 1).** Owns \(\mathbf Y\), \(\boldsymbol\mu\), \(\log\mathbf S\), a seeded sampler (`mt19937_64`), \(K\), and an SVGP core over the chosen kernel and `CInducing`. `objectiveGradBatch` draws \(\boldsymbol\epsilon\), forms \(\tilde{\mathbf X}_B\), calls the core, maps gradients to \((\boldsymbol\mu,\log\mathbf S)\) and adds the KL terms. `afterBatchStep` takes the natural-gradient step on \(q(\mathbf v)\).
4. **Surfaces (Phase 4).**
   - `bgplvm --inference svi [--batch B] [--samples K] [--inducing points|whitenoise|weightspace|greens]`, alongside the existing `-k`, `-M`, `--seed`, `--latent-dim`.
   - Stream version with the inference type and \(q(\mathbf X)\) (`svibayesgplvm`).
   - Docs/tutorial + smoke. Python façade ([CIP-001D](./cip001D.md)) and MRD with a shared \(q(\mathbf X)\) are follow-on backlog items.

**Cost per step:** \(O(K|B|M^2+M^3+K|B|M\,c_\phi)\), where \(c_\phi\) is the cost of one feature. Memory is \(O(NQ+dM^2)\). There is no \(N\times M\) storage beyond a batch.

### Verification oracles

| ID | Check | Oracle |
|---|---|---|
| V1 | \(\mathbf S\to0\) reduction | \(\hat{\mathcal L}+\mathrm{KL}(q(\mathbf X))\) equals `CSvgp` ELBO at inputs \(\boldsymbol\mu\); at the \(q(\mathbf v)\) optimum equals `CGp` DTCVAR at \(\boldsymbol\mu\) (round-off) |
| V2 | Unbiasedness (RBF / RBF-ARD, points, Gaussian) | Exact \(\mathcal L\) at any \(q(\mathbf v)\) from \(\psi_0,\Psi_1,\Psi_2\) (data term is linear in them); mean of \(10^4\) estimates within 4 s.e. |
| V3 | Collapsed limit | With \(q(\mathbf v)\) at its psi-based optimum \(\tilde S^*=(I+\beta L^{-1}\Psi_2L^{-\top})^{-1}\), \(\tilde{\mathbf m}^*_j=\beta\tilde S^*L^{-1}\Psi_1^\top\mathbf y_j\): exact \(\mathcal L\) equals `CBayesGplvm` bound \(-\mathrm{KL}\) to round-off; the MC estimate agrees within s.e. |
| V4 | Gradients | Finite differences at fixed \(\boldsymbol\epsilon\) for \(\boldsymbol\mu,\log\mathbf S\), kernel, inducing and noise parameters, for points, white-noise RBF, weight-space ridge (erf, soft-ReLU) and Green's (1-D) |
| V5 | Gradient unbiasedness | Mean stochastic gradient vs gradient of the psi-based exact \(\mathcal L\) (V2 setting), within s.e. |
| V6 | Minibatch | Average over a partition equals full batch at fixed \(\boldsymbol\epsilon\) (exact) |
| V7 | Reproducibility | Same seed gives an identical trajectory (single thread) |
| V8 | End-to-end | On the `demo_bayes_gplvm` data: SVI with RBF / points reaches the collapsed optimum bound within MC error; weight-space MLP runs, with its final ELBO estimated with \(K=1000\) |

V2 and V3 make the collapsed `CBayesGplvm` a **reference implementation** for the new estimator wherever psi statistics exist.

### Practical guidance

- Prefer collapsed `CBayesGplvm` when psi statistics exist and \(N\) fits: it is deterministic and tighter for the same \(q(\mathbf X)\).
- Use the SVI variant for kernels or inducing families without psi statistics, or for large \(N\).
- Expect slower, noisier convergence for \(\log\mathbf S\) than for \(\boldsymbol\mu\). Larger \(K\) or batches and antithetic samples help.

### Explicit non-goals

- Amortised or back-constrained \(q(\mathbf X)\) (encoder networks).
- Dynamics priors.
- Deep GPs (out of scope here; Phase 0b is the intended layer surface for a later DSVI deep-GP CIP — see CIP-0028 deep-extension notes for mean/variance scaling).
- GPU backends ([REQ-0016](../requirements/req0016_gpu-training-decision.md)).
- SSGPLVM.
- Natural gradients for \(q(\mathbf X)\) (a possible later extension: local factors are Gaussian too).
- Any change to collapsed `CBayesGplvm` / `CMrd` behaviour.

### Tenets

- **Assert and verify:** exact psi-based oracles (V2, V3), the reduction to `CSvgp` / `CGp` (V1), and finite-difference and unbiasedness checks.
- **Compose through interfaces:** everything goes through `CInducing` and the kernel's input gradients; no family-specific code in the model.
- **Flexibility without a performance tax:** minibatch cost independent of \(N\); batched BLAS-3 core.
- **LAPACK owns the linear algebra:** Cholesky / `trsm` only; reuse of the existing adjoints.

## Implementation Plan

1. **Phase 0a — `CSvgp` via `CInducing`.**
   - Gate: `testSvgp` unchanged with points.
   - New SVGP finite-difference checks for white-noise, weight-space and Green's features.
   - SVGP ELBO \(\le\) exact log marginal at small \(N\) for each family.
2. **Phase 0b — explicit-input core with input gradients.**
   - Gate: \(\partial\)ELBO\(/\partial\mathbf X\) finite differences for all families.
   - Batch-partition exactness.
3. **Phase 1 — `CSviBayesGplvm`, Gaussian likelihood.**
   - Points / RBF first.
   - Gates: V1–V3, V5–V7.
4. **Phase 2 — inducing families.**
   - White-noise RBF, weight-space ridge (erf, soft-ReLU), Green's.
   - Gates: V4; V8 demo for MLP.
5. **Phase 3 — non-Gaussian likelihoods.**
   - Probit / ordered via Gauss–Hermite, i.e. a Bayesian GP-LVM for binary data.
   - Gates: V4; ELBO \(\le\) exact for tiny problems by orthant probability (the 2026-11-18 PPA harness).
6. **Phase 4 — surfaces.**
   - CLI flags, stream version, Python façade, docs/tutorial.
   - MRD with shared \(q(\mathbf X)\) as a follow-on.

## Backward Compatibility

- `CBayesGplvm`, `CMrd`, collapsed CLI behaviour and stream versions are unchanged.
- `CSvgp` keeps its `Z` constructor and outputs (it wraps `CInducingPoints`); a new constructor takes `CInducing&`.
- The new CLI flags are additive. The default `bgplvm` inference stays collapsed.

## Testing Strategy

- New `testSviBayesGplvm` (matio-free) covering V1–V7. V2, V3 and V5 use the CIP-0017 psi code as the oracle; tolerance is stated in standard errors with fixed seeds, so tests are deterministic.
- Extend `testSvgp` for Phase 0 (inducing families, input gradients).
- V8 as a demo smoke in CI with a short run and a recorded ELBO range.
- Coverage gates per [CIP-002E](./cip002E.md) tiers: unit tests in the hard tier; demo smoke in the numerics tier.
