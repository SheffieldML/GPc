# CIP-0032: Per-unit window widths for weight-space ridges

> CIPs describe HOW to achieve requirements (WHAT). This CIP extends [CIP-0028](./cip0028.md) so each ridge unit can learn its own window width \(s_m\), restoring the per-unit sharpness freedom that a finite MLP gets from \(\|\mathbf w_m\|\).

## Summary

[CIP-0028](./cip0028.md) ships ridge windows in prior-whitened weight space with a **single global** softness \(s\). Free centres \((\mathbf v_m,a_m)\) already give an MLP-**shaped** posterior mean (a bank of smoothed erf / soft-ReLU units). They do **not** give MLP-**equivalent** per-unit scale: a standard net sharpens unit \(m\) by growing \(\|\mathbf w_m\|\); here \(\mathbf v_m\) lives on the sphere, \(s\) is shared, and kernel \(\Sigma\) rescales all inputs together via \(\hat{\mathbf x}=\Sigma^{1/2}\tilde{\mathbf x}\).

This CIP adds a positive vector \(\mathbf s\in\mathbb R^M_{>0}\) (per-inducing window widths), with the current scalar \(s\) as the tied special case and the default. Opt-in learning of \(\{s_m\}\) restores independent unit sharpness on the VIK side. We document that \(s_m\) is **window width**, not a literal reparameterisation of \(\|\mathbf w_m\|\), while playing the same modelling role.

**Which requirements?** [REQ-000D](../requirements/req000D_jitter-free-sparse-conditioning.md) (kernel-free \(K_{uu}\) retained), [REQ-0002](../requirements/req0002_runnable-verification.md) (FD / quadrature gates), [REQ-000E](../requirements/req000E_gpy-facing-python-facade.md) (façade paths / display).

## Motivation

### Finite MLP mean vs shared \(s\)

With free ridges, the sparse posterior mean has the functional form

\[
m(\mathbf x)=\sum_m \alpha_m\, A_m(s)\,\operatorname{erf}\!\big(\ell_m(\mathbf x;\mathbf v_m,a_m,s)\big)
\]

(or soft-ReLU for arc-cosine order 1). That is a single-hidden-layer network with **one shared activation softness**.

In a usual MLP,

\[
\operatorname{erf}(\mathbf w_m^\top\tilde{\mathbf x})
=\operatorname{erf}\big(\|\mathbf w_m\|\,(\hat{\mathbf w}_m^\top\tilde{\mathbf x})\big),
\]

so unit \(m\) hardens by growing \(\|\mathbf w_m\|\) alone. Under CIP-0028:

- \(\mathbf v_m\) is unit-length;
- global \(s\) sets every unit’s window;
- \(\Sigma\) (weight / bias variance) only stretches **all** \(\hat{\mathbf x}\) together;
- mean coefficients \(\alpha_m\) change amplitude, not erf slope;
- offsets \(a_m\) move thresholds (\(\mu_m\propto a_m\)), they do not restore a free per-unit \(\|\mathbf w_m\|\).

Partial compensation by raising weight variance exists near the origin (slope \(\propto\Sigma^{1/2}\)), but it is not a reparameterisation of \(s\), and it saturates in the angular / large-\(\Sigma\) limit where softness is again only \(s\) ([CIP-0028](./cip0028.md) Mathematics). Empirically \(K_{fu}\) vs weight variance at fixed window is already non-monotone.

### What CIP-0028 deferred

The backlog item [`2026-11-21_weightspace-learn-window-width`](../backlog/features/2026-11-21_weightspace-learn-window-width.md) wired **one global** learnable \(s\) (`learn_window_width=True`). Per-inducing \(s_m\) was an explicit non-goal. Global learning is necessary but not sufficient for mean function to MLP-equivalent per-unit scale.

## Detailed Description

### Parameterisation

Keep the CIP-0028 ridge in whitened \(\boldsymbol\omega\):

\[
\psi_m(\boldsymbol\omega)=g_m(\mathbf v_m^\top\boldsymbol\omega)\,\sqrt{\mathcal N(\Pi_m^\perp\boldsymbol\omega;\mathbf 0,I)},
\qquad
g_m(t)=(\pi s_m^2)^{-1/4}\exp\big(-(t-a_m)^2/(2s_m^2)\big).
\]

Tied mode: \(s_m\equiv s\) for all \(m\) (today’s behaviour; default). Untied mode: each \(s_m>0\) free when inducing centres are free.

**Role vs map.** \(s_m\) is the VIK window width for unit \(m\). Smaller \(s_m\) approaches a harder activation; larger \(s_m\) softens. That matches the *role* of \(\|\mathbf w_m\|\) for independent sharpness. It is not algebraically the same object as multiplying the linear form by \(\lambda_m\) inside an exact \(\operatorname{erf}\). Exact MLP scale is closer to free \(\lambda_m\) (or unconstrained \(\mathbf w_m\)) with \(s\to 0\); we stay inside the window construction and untie \(s_m\).

### Closed forms (sketch; derive in Phase A)

**\(K_{fu}\).** The CIP-0028 column formulae already factor per unit. Replace scalar \(s\) by \(s_m\):

\[
c_m=\frac{2s_m^2}{2+s_m^2},\quad
\mu_m=\frac{a_m c_m}{s_m^2},\quad
A_m=A(s_m,a_m),
\]

and the erf argument as in CIP-0028 with \((c_m,\mu_m)\) and \(\hat{\mathbf x}=\Sigma^{1/2}\tilde{\mathbf x}\). Arc-cosine order 0/1 follows the same substitution.

**\(K_{uu}\).** Today’s pair formula uses a single \(\alpha=s^{-2}-\tfrac12\) and cosine \(c=\mathbf v_m^\top\mathbf v_n\). Generalise to \((\alpha_m,\alpha_n,c)\) with \(\alpha_m=s_m^{-2}-\tfrac12\) (and likewise \(\alpha_n\)). Retain \(2\times2\) Sylvester / Woodbury structure in \(\mathrm{span}\{\mathbf v_m,\mathbf v_n\}\). Require:

- \(s_m\equiv s\) recovers the shipped formula;
- \(\mathrm{diag}(K_{uu})=1\) by \(L^2\) normalisation of each \(\psi_m\);
- \(\kappa(K_{uu})\) recorded under a fixed budget (same spirit as CIP-0028 variance-captured gates).

Phase A owns the analytic derivation and a quadrature / Monte Carlo oracle before any production path depends on it.

### Gradients and packing

- Extend `gradFromKuuKuf` so \(\partial L/\partial s_m\) accumulates from \(K_{uu}\) and \(K_{uf}\) (analytic preferred; FD only as test oracle).
- `getNumParams` / `getParams` / `setParams`: when untied and `learnS`, append \(M\) positive widths (exp / negLogLogit transform), not one scalar.
- `CGp` packing already routes through `CInducing::getNumParams`; no new sparse algebra beyond inducing.
- Global `learn_window_width` remains the tied path (one \(s\)). Untied learning is a separate opt-in (below).

### API and display

| Surface | Tied (default) | Untied |
|---|---|---|
| C++ | `setWindowWidth(s)` / `getWindowWidth()` | `setWindowWidths(sVec)` / `getWindowWidths()`; scalar setters broadcast |
| Learn flag | `setLearnWindowWidth` (one \(s\)) | `setLearnWindowWidths` / equivalent; requires free inducing |
| Paths | `inducing.window_width` | `inducing.window_width.<m>` (and bulk get/set if cheap) |
| Python | `window_width=float`, `learn_window_width=bool` | `window_width` array length \(M\`, or `learn_window_widths=True` initialised from scalar / median recipe |
| `describe` / `str` | one row (today) | summary row plus optional first-\(k\) samples, or full list when \(M\) small; `opt_num_params` must include all free \(s_m\) |

Stream / `.model`: version bump or additive field `windowWidths` (\(M\) doubles); old files with scalar `windowWidth` load as tied.

### Default policy and conditioning

- **Initially default stays tied and fixed** (CIP-001C / 0028 policy): conditioning of \(K_{uu}\) is dominated by window overlap; untying \(M\) widths raises the chance that some \(s_m\to 0\) and \(\kappa\) blows up.
- Untied + learn: document the risk; init all \(s_m\) from the current ridge init (\(s\) from offset spacing under \(\kappa\le10^4\)); optional floor / soft prior on \(s_m\) deferred unless soak demands it.
- `learn_window_widths=True` with `inducing_fixed=True` errors (same rule as global learn). Testing may change this.

### Locked decisions

1. **Scope:** `CInducingWeightSpace` ridge (and isotropic oracle if still compiled). White-noise / Green’s per-centre \(s_m\) are out of scope (separate CIP if needed).
2. **Tied scalar remains default**; untied is opt-in.
3. **Prefer untied \(s_m\)** over introducing a free per-unit \(\lambda_m\) on unit directions in this CIP (rejected alternative below).
4. **Python** exposes untied learning without breaking existing `learn_window_width` semantics.
5. **SVGP** (`CSvgp`) follows only if Phase 0 of [CIP-0030](./cip0030.md) already routes inducing params through `CInducing`; otherwise backlog follow-on, not a blocker for `CGp`.

### Alternatives considered

1. **Free per-unit scale \(\lambda_m\) with fixed / global \(s\).** Closer to literal \(\|\mathbf w_m\|\), but changes the ridge parameterisation (sphere \(\times\) scale) and still needs a policy for \(s\). Rejected for this CIP: we already have a window parameter; untying it is the minimal extension of CIP-0028.
2. **Drive global \(s\to 0\) and rely on \(\Sigma\) / centres.** Does not restore per-unit sharpness; \(\Sigma\) is shared; small global \(s\) hurts \(\kappa(K_{uu})\).
3. **Dutordoir / RKHS exact activations.** Different construction (kernel-dependent \(K_{uu}\)); out of scope — stay on VIK windows.
4. **Per-unit \(s_m\) only as fixed user vector (no gradients).** Useful for ablation but does not address “MLP can grow \(\|\mathbf w_m\|\)” during optimisation; ship learnable untied as the goal, fixed untied as a subset.

## Implementation Plan

1. **Phase A — Maths and oracles:** Derive heterogeneous-\(s\) \(K_{uu}\) and confirm \(K_{fu}\) column substitution; quadrature (\(D'=2\)) and MC (\(D'\ge8\)); FD on \(\partial/\partial s_m\). Document formulae in this CIP or `cip/cip0032/`.
2. **Phase B — `CInducingWeightSpace` + `CGp`:** Store \(\mathbf s\); tied/untied modes; pack/unpack; analytic grads; stream round-trip; \(\kappa\) / variance-captured soak with untied init.
3. **Phase C — Façade and docs:** Python API + paths + `describe`; notebook cell (weight-space ridge) comparing tied vs untied; `docs/numerics.md` / CIP-0028 cross-link; update deferred note in the global-learn backlog.

## Backward Compatibility

- Default construct and CLI / Python recipes that pass a scalar `window_width` keep today’s tied behaviour.
- `learn_window_width=True` stays “one global free \(s\)”.
- Old streams with scalar `windowWidth` load as tied; new field only when untied or when saving explicit vectors.

## Testing Strategy

- Tied recovery: untied with \(s_m\equiv s\) matches CIP-0028 \(K_{uu}\)/\(K_{fu}\) to tight tol.
- FD: \(\partial L/\partial s_m\) vs finite differences (ridge MLP and arccos-0).
- Optim smoke: untied learn moves at least one \(s_m\) and does not NaN; \(\kappa(K_{uu})\) logged.
- Display: `param_paths` lists `inducing.window_width.<m>` when untied; `opt_num_params` counts them.
- Façade: scalar API unchanged; array / `learn_window_widths` smoke in `test_weightspace` / `test_sparse_dtcvar`.
