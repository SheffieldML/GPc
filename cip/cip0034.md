## What this CIP does

1. **Single site buffer path** — `getMu` / `setMu` / `getVarSigma` / `setVarSigma` live only on `CNoise` base; subclass duplicates removed.
2. **Storage** — per-point `mu` / `varSigma` live in `CNoiseSiteWorkspace` (`ownedSites`, or an attached external workspace from IVM / PPA).
3. **Attach** — `CIvm`, `CPpa`, `CSparsePpa` attach inference-owned workspaces.
4. **`py`** — remains a **non-owning** pointer (model / dataset owns \(Y\)); documented as satisfying “no owned targets on the likelihood.” Removing the pointer field entirely is a separate API change (not required to close REQ-0019’s site-cache clause).

## Non-goals

- Changing IVM White softener
- Sparse EP
- Moving all `logLikelihood()` oracles off site buffers in one go (they still *read* sites via accessors)
