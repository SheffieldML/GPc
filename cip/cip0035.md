# CIP-0035: Deep GPs by doubly stochastic variational inference on the SVGP layer core

> CIPs describe HOW to achieve requirements (WHAT). This CIP implements [REQ-001A](../requirements/req001A_deep-gaussian-processes.md). It stacks the explicit-input SVGP core delivered by [CIP-0030](./cip0030.md) Phase 0b into a deep GP trained by doubly stochastic variational inference (Salimbeni & Deisenroth 2017), with any `CInducing` family per layer. Design defaults come from a JAX prototype ([`cip0035/prototype/`](./cip0035/prototype/)) and the depth notes in [CIP-0028](./cip0028.md) §4.

## Summary

A deep GP is a stack of \(L\) GP layers, \(\mathbf h_\ell=\mathbf m_\ell(\mathbf h_{\ell-1})+\mathbf f_\ell(\mathbf h_{\ell-1})\), \(\mathbf h_0=\mathbf x\). Each layer is an SVGP with a whitened \(q(\mathbf v_\ell)\). Training propagates reparameterised samples through the layers, point by point, and optimises an unbiased estimate of the ELBO on minibatches. Every piece except one already exists in GPc:

- the explicit-input core `CSvgp::dataTermAt` / `elboGradAt(..., gX)` (CIP-0030 Phase 0b), used as-is for the **final** layer;
- all four `CInducing` families with input gradients, through `CSvgp` (CIP-0030 Phase 0a);
- `CStochasticOptimisable`, `CAdam`, seeded sampling and minibatches.

**The missing piece** is a layer API for **hidden** layers: their "likelihood" is the rest of the network, so the core must return the per-point marginals \((\boldsymbol\mu,\mathbf v)\) of \(\mathbf f_\ell\) at caller-supplied inputs and accept upstream gradients \((\bar{\boldsymbol\mu},\bar{\mathbf v})\). Hidden layers also need \(q(\mathbf v)\) gradients for Adam, since the CVI natural-gradient step assumes a log-concave likelihood term it cannot see here.

**Defaults, from the prototype:** identity mean functions (PCA projection on the first layer), per-layer kernel variance \(\chi/(L-1)\) on hidden layers, **inducing points in hidden layers**, and weight-space windows only in learned form. Fixed weight-space windows underfit in hidden layers; the evidence is below.

## Motivation

- **Depth matters on compositional data, and GPc cannot fit it.** On the prototype's composite task (10-D input; the target is a nonlinear function of a 2-D projection), the exact one-layer GP with the MLP kernel reaches test RMSE 0.833; one-layer sparse models reach 0.92–0.97. A three-layer deep GP reaches 0.229.
- **The Bayesian layers buy accuracy and calibration over a classical network of the same shape.** An MLP with the deep GP's block structure (linear skip path, width-5 bottleneck, erf units), tuned on a validation split, reaches RMSE 0.340 ± 0.024 and NLL 0.36; an ensemble of five reaches 0.288 / 0.19. The inducing-point deep GP reaches 0.229 / −0.25 without tuning. Plain MLPs (2–3 hidden layers × 64, ReLU or tanh) reach only 0.70–0.78.
- **CIP-0030 built the layer surface for this.** Its Phase 0b kept the core free of \(q(\mathbf X)\) ownership precisely so a deep-GP CIP could stack it without reopening SVGP.
- **Weight-space MLP features (CIP-0028) need a deep home.** Whether they are a good one is an empirical question; this CIP records the answer (mostly no, unless learned) and keeps them as an option.

## Detailed Description

### Model

Layer \(\ell=1,\dots,L\) maps \(\mathbf h_{\ell-1}\in\mathbb R^{D_{\ell-1}}\) to \(\mathbf h_\ell\in\mathbb R^{D_\ell}\), with \(D_0=d\), \(D_L=p\) (outputs) and hidden width \(D\).

- **Mean function** \(\mathbf m_\ell(\mathbf h)=\mathbf h P_\ell\), fixed: \(P_1\) = top-\(D\) principal directions of \(\mathbf X\) when \(d\ne D\) (identity when equal); \(P_\ell=I\) for hidden layers; \(\mathbf m_L=\mathbf 0\). This is Salimbeni & Deisenroth's choice and the skip path that makes the MLP comparison work.
- **GP part** \(\mathbf f_\ell\): \(D_\ell\) independent outputs sharing a kernel \(k_\ell\) and an inducing family, whitened \(q(\mathbf v_{\ell j})=\mathcal N(\tilde{\mathbf m}_{\ell j},\tilde S_{\ell j})\), \(\mathbf u=L_{uu}\mathbf v\). With \(\mathbf a(\mathbf h)=L_{uu}^{-1}K_u(\mathbf h)\):
\[
q(f_{\ell j}(\mathbf h))=\mathcal N\big(\mathbf a^\top\tilde{\mathbf m}_{\ell j},\;k_\ell(\mathbf h,\mathbf h)-\mathbf a^\top\mathbf a+\mathbf a^\top\tilde S_{\ell j}\mathbf a\big).
\]
- **Bound** (Salimbeni & Deisenroth 2017, eq. 4):
\[
\mathcal L=\sum_{n}\mathbb E_{q(\mathbf h_{L-1,n})}\mathbb E_{q(\mathbf f_{L}(\mathbf h_{L-1,n}))}\log p(\mathbf y_n\mid\mathbf f_{L})-\sum_{\ell,j}\mathrm{KL}\big(q(\mathbf v_{\ell j})\,\|\,\mathcal N(\mathbf 0,I)\big),
\]
where \(q(\mathbf h_{L-1,n})\) is obtained by sampling layer by layer **using only per-point marginals**: \(\tilde{\mathbf h}_{\ell,n}=\mathbf m_\ell(\tilde{\mathbf h}_{\ell-1,n})+\boldsymbol\mu_\ell(\tilde{\mathbf h}_{\ell-1,n})+\sqrt{\mathbf v_\ell(\tilde{\mathbf h}_{\ell-1,n})}\odot\boldsymbol\epsilon_{\ell n}\).

The final layer's inner expectation is closed form for Gaussian noise and Gauss–Hermite for probit / ordered, through the existing `CSvgp` path.

### Depth defaults

- **Per-layer kernel variance.** Hidden layers start at \(\sigma^2_\ell=\chi/(L-1)\) with \(\chi=1\); the final layer at the output variance. With identity means this keeps the prior end-to-end Jacobian well conditioned at any depth. Spread of log singular values (max − min), prior draws through ridge-window layers, width 8, \(M=64\) (prototype `dgp_jacobian.py`):

  | stack | \(L=1\) | 2 | 4 | 8 | 16 | 32 | log-log slope |
  |---|---|---|---|---|---|---|---|
  | zero mean, \(\chi=1\) (plain deep GP) | 3.4 | 5.3 | 9.0 | 15.0 | 28.2 | 36.6 | 0.72 |
  | identity mean, \(\chi=1\) | 1.6 | 2.2 | 2.9 | 3.7 | 4.5 | 5.5 | 0.34 |
  | identity mean, \(\chi=1/L\) | 1.5 | 1.5 | 1.4 | 1.4 | 1.4 | 1.4 | −0.01 |

  CIP-0028 §4 point 3 reports \(\sqrt L\) growth; that table held \(\chi_f=1/64\) fixed across depths. Scaling \(\chi\) with depth removes the growth.
- **Initial \(q(\mathbf v)\).** Hidden layers \(\tilde{\mathbf m}=\mathbf 0\), \(\tilde S=10^{-4}I\) (so the network starts as its mean path); final layer \(\tilde S=I\).
- **Inducing initialisation.** Points: a random subset of \(\mathbf X\), pushed through the mean functions for each layer (Salimbeni & Deisenroth). Weight-space: `makeRidgeInit` with the layout fixes in Phase 0c.

### Inducing families per layer

| family | where | status in this CIP |
|---|---|---|
| inducing points | any layer | **default** for hidden layers |
| weight-space ridge, learned \((\mathbf v_m,a_m,s_m)\) | any layer | supported; \(s\le1\) bound (`windowWidthMax`) enforced |
| weight-space ridge / white-noise / Green's, fixed | final layer | supported; **not recommended in hidden layers** |
| finite-network mode (residual off) | weight-space layers | Phase 4 option, labelled as a bound on a different model |

Evidence (composite task, three layers, hidden width 5; RMSE / NLL / ELBO per point):

| layers | \(M=64\) | \(M=128\) |
|---|---|---|
| inducing points | **0.229 / −0.25 / −0.08** | 0.238 / −0.22 / −0.12 |
| learned ridge windows | 0.282 / −0.00 / −0.41 | 0.258 / −0.05 / −0.35 |
| random erf units (finite net, reference) | 0.268 / 0.02 / −0.28 | 0.266 / −0.03 / −0.29 |
| fixed Hermite windows | 0.546 / 0.79 / −1.01 | 0.315 / 0.21 / −0.63 |
| fixed ridge windows | 0.521 / 0.77 / −1.00 | 0.623 / 0.95 / −1.10 |
| fixed windows, residual dropped | 0.28 / 0.13–0.14 | 0.27–0.37 / 0.12–0.42 |

**Why fixed windows fail in hidden layers.** The residual variance \(k-\mathbf a^\top\mathbf a\) — what the windows miss — enters every hidden layer as injected noise. Training avoids it by holding hyperparameters where the windows capture 92–99% of the prior variance, i.e. the near-linear regime, and the network underfits. Without the residual the trained layers sit where windows capture only 70–85%. This is the low-dimension plateau of fixed windows (CIP-0028) appearing as noise at every layer. Inducing points avoid it by moving to the data; in a trained network the hidden states lie on a low-dimensional manifold, which data-blind windows cannot track. Wider hidden layers do not rescue fixed windows: at \(D=16\)/32, \(M=128\), inducing points reach 0.251/0.284, learned ridges 0.286/0.599, fixed Hermite 0.678/0.696.

**Learned windows** recover most of the gap but need \(K_{uu}\) refactorised each step (the same \(O(M^3)\) as points). In the unclamped prototype the first layer's width drifted to \(s\approx1.2\)–1.4 and \(\kappa(K_{uu})\) reached \(10^5\)–\(10^6\), heading for the \(s=\sqrt2\) degeneracy. GPc's existing bound \(s\le1\) is therefore required, not optional.

### Layer API (the missing piece)

Add to `CSvgp`, alongside the Phase 0b methods:

```cpp
// Per-point marginals of f at caller inputs XB (B x q): mean, var are B x p.
void marginalsAt(const CMatrix& XB, CMatrix& mean, CMatrix& var) const;
// Backward pass given upstream gradients of the objective w.r.t. mean and var
// (B x p). Accumulates into gKern, gInducing, gQ (q(v) params in Cholesky mode),
// and optionally gX (B x q). Does not include KL(q(v)) — see klGrad.
void marginalsGradAt(const CMatrix& XB, const CMatrix& gMean, const CMatrix& gVar,
                     CMatrix& gKern, CMatrix& gInducing, CMatrix& gQ,
                     CMatrix* gXOrNull) const;
double klQ(CMatrix* gQOrNull) const;   // sum_j KL(q(v_j) || N(0,I)) and its gradient
```

- `marginalsGradAt` is the existing `elboGradAt` with the likelihood's \((g^\mu,g^v)\) replaced by the caller's \((\bar{\boldsymbol\mu},\bar{\mathbf v})\); the whitening adjoints (`trsmAdjointUT`, `cholAdjointUpperBlocked`) and `gradFromKuuKuf(..., wantX)` are shared, not duplicated.
- **Cholesky mode for \(q(\mathbf v)\).** `CSvgp` holds \(\tilde S_j\) for CVI steps. Add a parameterisation \(\tilde S_j=L_jL_j^\top\) (lower triangular, log diagonal) with \((\tilde{\mathbf m}_j,L_j)\) packed into the stochastic parameters, so Adam can update them. KL and its gradient are \(O(M^2)\) per output in this form. CVI natural-gradient steps remain available for the final layer (Gaussian or log-concave likelihoods), as in the hybrid scheme of Salimbeni, Eleftheriadis & Hensman (2018); hidden layers use Adam only.
- **Shared covariance option.** A layer may share one \(\tilde S\) across its \(D_\ell\) outputs (matrix-normal \(q\)), cutting covariance cost and parameters by \(D_\ell\). Default: per-output, as `CSvgp` does today.

### `CDeepGp : CStochasticOptimisable`

- Owns \(\mathbf X,\mathbf Y\), the fixed mean matrices \(P_\ell\), \(L\) `CSvgp` layer cores (each with its own kernel and `CInducing`), a seeded `mt19937_64`, the number of samples \(K\) per point, and the likelihood (through the final layer's core).
- **`objectiveGradBatch(batch, g)`:**
  1. Draw \(\boldsymbol\epsilon_{\ell n k}\) (injectable for tests, per [`docs/target-architecture.md`](../docs/target-architecture.md)).
  2. Forward: for \(\ell<L\), `marginalsAt` then \(\tilde{\mathbf h}_\ell=\tilde{\mathbf h}_{\ell-1}P_\ell+\boldsymbol\mu+\sqrt{\mathbf v}\odot\boldsymbol\epsilon\). Final layer: `elboGradAt(..., gX)` on \(\tilde{\mathbf h}_{L-1}\) with weight \(c=N/(|B|K)\).
  3. Backward: \(\bar{\mathbf h}_{\ell-1}=\bar{\mathbf h}_\ell P_\ell^\top+\) `gX` from `marginalsGradAt` with \(\bar{\boldsymbol\mu}=\bar{\mathbf h}_\ell\), \(\bar{\mathbf v}=\bar{\mathbf h}_\ell\odot\boldsymbol\epsilon/(2\sqrt{\mathbf v})\).
  4. Add \(-\sum_\ell\) `klQ` once per step (not scaled by \(N/|B|\)).
- **`afterBatchStep`:** optional CVI step on the final layer only, \(\gamma<1\) with a decaying schedule (inputs are sampled).
- **Prediction:** \(S\) samples through the network; predictive density as a mixture (log-mean-exp), predictive mean and variance by the mixture moments. Expose latent and predictive variants as in [CIP-0031](./cip0031.md).

### Cost per step

With \(B\) points, \(K\) samples and \(M_\ell\) inducing per layer:
\[
O\Big(\sum_\ell \big(KB M_\ell^2 D_\ell+M_\ell^3+KBM_\ell c_\phi\big)\Big),
\]
where \(c_\phi\) is the cost of one feature. Memory \(O(\sum_\ell D_\ell M_\ell^2)\); nothing scales with \(N\) beyond the data. Prototype timings (CPU, \(L=5\), width 8, \(B=256\)): inducing points 9 ms at \(M=64\), 62 ms at 256, 1.1 s at 1024, against 3 / 7 / 22 ms for a deep MLP of the same shape. Finite-network weight-space layers with one weight draw per minibatch run at MLP cost up to a few hundred units (2.4 / 11 / 103 ms); the residual alone adds an \(O(BM^2)\) Nyström diagonal.

### Phase 0c: ridge layout fixes (prerequisite for weight-space layers)

Two findings from the prototype that apply to `CInducingWeightSpace::makeRidgeInit` regardless of depth:

- **Symmetric offsets waste half the windows.** erf is odd, so windows at \(\pm a\) on one direction give \(K_{fu}\) columns that are exact negatives: with offsets on \([-2.5,2.5]\), \(\operatorname{rank}K_{fu}=M/2\) exactly. Use one-sided offsets (e.g. \([1,2.5]\)).
- **Directions before offsets once \(D'\) is moderate.** At \(M=128\), 128 directions × 1 offset beat 32 × 4: variance captured 0.974 vs 0.920 at \(d=16\), 0.818 vs 0.397 at \(d=64\); offsets win only at \(d=4\) (0.944 vs 0.822). The current cap of \(D'\) directions is the wrong way round above small \(d\).

Gate: \(\operatorname{rank}K_{fu}=M\) for the default layout; CIP-0028's variance-captured gates still pass.

### Practical guidance

- Use inducing points in hidden layers. Use learned weight-space ridges where the MLP interpretation matters, accepting a looser bound.
- Keep hidden widths small (the prototype used 5); depth with identity means is cheap, width is not.
- Fit a one-layer `CSvgp` first; if a deep model does not beat it, the data are not compositional enough to justify depth.
- Expect noisier, slower convergence than `CSvgp`; \(K>1\) samples or larger batches help, as does a warm start from the mean path.

### Explicit non-goals

- Deep GP-LVM (latent inputs at the top; would compose with `CSviBayesGplvm`) — follow-on.
- Natural gradients for hidden layers.
- Learned mean functions, convolutional or attention layers, skip connections beyond the mean path.
- Non-Gaussian hidden-layer posteriors (SGHMC / importance-weighted deep GPs).
- Fixed weight-space windows as a hidden-layer default; Hermite windows in hidden layers.
- GPU backends ([REQ-0016](../requirements/req0016_gpu-training-decision.md)).
- Any change to `CSvgp`, `CSviBayesGplvm` or `CGp` default behaviour.

### Tenets

- **Assert and verify:** exact oracles at \(L=1\) and \(L=2\) (V1–V3), finite differences, unbiasedness in standard errors.
- **Compose through interfaces:** layers are `CSvgp` cores over `CInducing`; no family-specific code in `CDeepGp`.
- **Flexibility without a performance tax:** minibatch cost independent of \(N\); batched BLAS-3 core per [CIP-002D](./cip002D.md).
- **LAPACK owns the linear algebra:** Cholesky / `trsm` with the existing adjoints.

## Implementation Plan

1. **Phase 0a — Cholesky-mode \(q(\mathbf v)\) in `CSvgp`.**
   - Gate: Adam on \((\tilde{\mathbf m},L)\) reaches the CVI optimum on `testSvgp` problems; FD on \(q\) parameters; KL gradient FD.
2. **Phase 0b — layer API** (`marginalsAt`, `marginalsGradAt`, `klQ`).
   - Gate: FD for all families; `elboGradAt` reproduced by chaining `marginalsGradAt` with the likelihood's \((g^\mu,g^v)\) (round-off).
3. **Phase 0c — ridge layout fixes** (above). Independently shippable.
4. **Phase 1 — `CDeepGp`, Gaussian likelihood, inducing points.**
   - Gates: V1–V6.
5. **Phase 2 — weight-space layers** (learned ridge; per-unit widths from [CIP-0032](./cip0032.md)).
   - Gates: V4 for ridges; \(s\le1\) respected under optimisation; V8 rows for learned ridges.
6. **Phase 3 — non-Gaussian final layer** (probit / ordered via Gauss–Hermite; optional final-layer CVI).
   - Gates: V4; ELBO \(\le\) exact for tiny problems (PPA orthant harness).
7. **Phase 4 — surfaces and options.**
   - `deepgp` CLI: `-L`, `--hidden D`, `-M` (per layer or list), `--inducing points|weightspace`, `--batch`, `--samples`, `--chi`, `--seed`; stream format `deepgp`.
   - Finite-network mode for weight-space layers (`--residual off`), documented as a bound on a finite Bayesian network, with the one-weight-draw fast path.
   - Shared-covariance option; Jacobian diagnostic utility (V7); docs/tutorial using the composite and step tasks.
   - Python façade (`gpc.models.DeepGP`) as a follow-on backlog item.

## Backward Compatibility

- `CSvgp` keeps its CVI mode as the default; Cholesky mode and the layer API are additive.
- `makeRidgeInit` layout changes (Phase 0c) alter default weight-space initialisation; existing fixtures pinned to the old layout get an explicit legacy flag or are re-recorded, and the change is noted in the CIP-0028 docs.
- New CLI, class and stream format; nothing existing changes behaviour.

## Testing Strategy

- New `testDeepGp` (matio-free) for V1–V7, with fixed seeds and tolerances stated in standard errors.
- Extend `testSvgp` for Cholesky mode and the layer API; extend `testInducing` for the Phase 0c rank gate.
- V8 as a numerics-tier smoke with a short run and a recorded RMSE / NLL range; the JAX prototype in [`cip0035/prototype/`](./cip0035/prototype/) is the reference for those numbers.
- Coverage gates per [CIP-002E](./cip002E.md): unit tests in the hard tier; the smoke in the numerics tier.
